## Project Overview

The **Cognitive Pattern Explorer** is an interactive educational web application built using **HTML, CSS, and Vanilla JavaScript**. It provides a self-reflection experience through scenarios, drag-and-drop activities, and personalized insights while avoiding any form of clinical assessment.

---

## Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure |
| CSS3 | Styling |
| JavaScript | Application Logic |
| Native Drag & Drop | Interactive Activities |

- Developed reusable drag-and-drop components.
- Implemented progress tracking.
- Created a personalized reflection journal.
- Improved responsive web design.
- Built a fully offline application.
- Designed a non-diagnostic educational experience.
