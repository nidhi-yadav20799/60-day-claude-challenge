# <span style="color:#4F46E5;">Day 36 - Psychology-Inspired Interactive Learning with Claude</span>

---

## <span style="color:#2563EB;">Project Overview</span>

The **Cognitive Pattern Explorer** is a psychology-inspired educational web application created with **HTML, CSS, and Vanilla JavaScript**. It provides an interactive self-reflection experience through everyday decision-making scenarios, drag-and-drop activities, and personalized insights.

This application is designed for learning purposes only and avoids any form of psychological diagnosis or clinical assessment.

---

## <span style="color:#16A34A;">Technologies Used</span>

- HTML5
- CSS3
- Vanilla JavaScript
- Native Drag & Drop API
- Local Browser Storage

---

## <span style="color:#EA580C;">Application Features</span>

- Calm Mode & Stress Mode
- Interactive Thinking Style Scenarios
- Drag-and-Drop Priority Ranking
- Timeline Arrangement Activity
- Personalized Reflection Journal
- Thinking Profile Percentage Breakdown
- Responsive Design
- Keyboard Accessibility
- Offline Support
- Smooth Animations
