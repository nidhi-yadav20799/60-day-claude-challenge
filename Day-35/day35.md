# Day 35 - Prompt Puzzle

## About

For Day 35, I built a Prompt Puzzle application to practice prompt engineering through interactive challenges. The application includes different puzzle types where users improve prompts, compare AI outputs, and learn prompt optimization.

## Features

- Domain and difficulty selection
- Interactive prompt challenges
- Live scoring system
- Prompt Performance Report
- Randomized scenarios
- Responsive design
