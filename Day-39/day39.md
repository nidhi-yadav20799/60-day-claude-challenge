# Day 39 – PDF Splitter & Merger

## Overview

Built a premium browser-based **PDF Splitter & Merger** using HTML, CSS, and JavaScript. The application processes PDF files entirely in the browser, allowing users to split and merge documents securely without uploading them to external servers.

---

# Features

## PDF Splitter

- Automatic page detection
- Page thumbnail preview
- Custom page ranges
- Split after selected pages
- Split every N pages
- Extract selected pages
- Output preview
- Page validation

## PDF Merger

- Drag & Drop upload
- Merge multiple PDF files
- Reorder files before merging
- File preview
- Download merged PDF

## Additional Features

- Responsive Design
- Dark & Light Theme
- Smooth Animations
- Keyboard Shortcuts
- Accessibility Support
- Client-side Processing
- Offline Support
