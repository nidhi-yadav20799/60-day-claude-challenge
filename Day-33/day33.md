# Day 33 – Media Integrity Analyzer

## Overview

On Day 33 of the 60 Day Claude Challenge, I built an interactive educational web application called **Media Integrity Analyzer** using Claude AI.

The application teaches users how to identify misleading headlines, recognize emotional manipulation, and evaluate media content through interactive challenges.

The entire application was developed as a **single offline HTML file** using only HTML, CSS, and Vanilla JavaScript.

---

# Project Objective

The objective of this project is to promote media literacy by helping users:

- Detect misleading headlines
- Recognize emotional manipulation
- Evaluate source reliability
- Understand audience targeting
- Improve critical thinking before believing or sharing information

---

# Features

## Challenge 1 – Headline Detective

Users:

- Read a fictional news headline
- Decide whether they would click it
- Identify exaggerated or misleading words
- Reveal the Headline Accuracy Score
- Compare it with a fair rewritten headline

---

## Challenge 2 – Emotion Detector

Users:

- Analyze a fictional social media post
- Identify emotional triggers
- Detect manipulation techniques
- View a neutral rewritten version
- Learn how emotional language influences decisions

---

## Live Media Integrity Metrics

The application continuously updates:

- Headline Accuracy
- Source Reliability
- Emotional Manipulation
- Audience Targeting

---

## Final Dashboard

The dashboard summarizes:

- Overall Media Integrity Score
- Biggest Red Flag
- Media Literacy Insights
- Practical Media Literacy Habits
- Replay with New Scenarios

# Key Learnings

- Headlines can exaggerate information to increase clicks.
- Emotional language strongly influences user behavior.
- Reading beyond the headline helps avoid misinformation.
- Critical thinking is essential before believing or sharing online content.
- Media literacy improves decision-making in the digital world.
